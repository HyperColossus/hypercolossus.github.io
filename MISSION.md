# Mission: Build the Riftbound collection UI through code

## Why
Learn to build and maintain the user's Hearthstone-style Riftbound tracker personally, improving coding skills through work on the actual interface.

## Success looks like
- Build the collection layout with HTML and CSS and explain the layout choices.
- Turn the layout into React components with filters and owned-card states.
- Diagnose visual issues and make changes without relying on completed code from the teacher.

## Constraints
- Preserve the existing tracker and collection data.
- Use short exercises, real project examples, and immediate feedback.
- Prior experience is awaiting the user's answer; do not assume mastery.

## Out of scope
None explicitly excluded yet.
