Layout quick reference

Element
An HTML building block, such as a div or button.
Parent / child
An element containing another element / the element inside it.
Class / selector
A class labels an element. A CSS selector such as .card-grid targets that label.
Declaration
A property and value: gap: 24px;.
Grid container
The parent with display: grid.
Grid item
A direct child of the grid container.
fr
A share of the available grid space. Four 1fr columns divide that space equally.
gap
Space between grid rows and columns.
.card-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 24px;
}
